# Neo MD 1.3.0 版本迭代记录 —— 插件生态

本版是 Neo MD 的**首个插件生态版本**：上线插件商店「50 款日常与协作插件套件」，把编辑器里最常出现的「记录、整理、会议、评审、分派」五类高频环节沉淀为可一键安装、可独立启用的单文件命令插件；并配套一套 6 类校验门禁，保证 50 款插件在 Web / Windows PC / Android 三个宿主中做到「一次命令 = 一次同步文档变更」。

## 新增：插件商店 50 款日常与协作插件

插件均为单文件 ES 模块，仅调用宿主提供的 6 个 API（`getMarkdown` / `setMarkdown` / `insertMarkdown` / `getTitle` / `notify` / `registerCommand`），无网络、无 DOM、无异步。按 5 个分组列全如下：

### 分组一 · 日常使用 · 时间与日志（10 款）

- **01 每日站会日志** —— 文末追加「昨日进展 / 今日计划 / 阻塞项」三段式站会日志。
- **02 日终复盘** —— 汇总已完成与未完成待办，生成「完成 / 遗留 / 明日计划」三块复盘。
- **03 时间块规划** —— 插入按小时划分的时间块规划表，用于时间盒管理。
- **04 番茄钟台账** —— 汇总全文番茄打卡为台账表并统计今日专注次数。
- **05 本周计划看板** —— 插入本周三项目标与周一至周日安排看板。
- **06 周报摘要** —— 按标题与待办完成情况生成结构化周进展摘要。
- **07 月度归档清单** —— 插入备份、归档、清理、复盘、下月目标五项月度清单。
- **08 截止日期登记表** —— 扫描日期与截止字样，生成排序登记表并标出过期项。
- **09 连续打卡追踪** —— 计算当前与最长连续天数并生成打卡热力条。
- **10 今日聚焦简报** —— 从待办中按优先级与截止日提炼今日三项聚焦任务。

### 分组二 · 日常使用 · 写作与整理（10 款）

- **11 字数仪表盘** —— 统计字数、词数、段落数与预计阅读时长。
- **12 待办进度条** —— 统计待办完成率并生成进度条与百分比。
- **13 标题自动编号** —— 为二三级标题补全或规范化多级序号。
- **14 目录重建** —— 读取标题层级重新生成带锚点的目录区块。
- **15 有序列表重编号** —— 修正错乱的有序列表序号为连续序列。
- **16 空行与行尾清理** —— 压缩连续空行、清除行尾空格与制表符。
- **17 金句摘录卡** —— 提取引用块内容去重生成编号摘录卡。
- **18 分隔线规范化** —— 统一各类分隔线写法为标准三短横。
- **19 强调与符号规范** —— 统一强调符号与半角/全角标点混用。
- **20 表格对齐整理** —— 按列宽补齐空格重新对齐 Markdown 表格。

### 分组三 · 日常任务 · 协作会议（10 款）

- **21 已完成任务归档** —— 归档已勾选待办到文末清单，原文位置保留。
- **22 任务优先级排序** —— 按 P0/P1/P2 标记在列表内稳定重排待办。
- **23 待办截止日扫描** —— 提取待办日期生成分「过期 / 今天 / 本周 / 以后」的截止看板。
- **24 今日待办聚焦** —— 筛出今日到期与未标日期待办，汇总为聚焦区块。
- **25 检查清单模板** —— 插入发布前四类检查项清单模板。
- **26 会议纪要简报** —— 插入含参会人、决议与行动项表格的纪要模板。
- **27 议程生成器** —— 按议题与时长插入会议议程表。
- **28 行动项汇总** —— 把标注负责人或截止日的行动项按人分组汇总。
- **29 决策记录** —— 收集「决策 / 结论 / 决定」条目生成决策记录表。
- **30 复盘四象限** —— 插入「做得好 / 待改进 / 值得尝试 / 下一步」复盘模板。

### 分组四 · 协作 · 评审与复盘（10 款）

- **31 代码评审清单** —— 插入正确性、可读性、测试、安全、性能五维评审清单。
- **32 变更说明模板** —— 插入背景、改动、影响、测试、回滚五段变更说明。

- **34 测试计划模板** —— 插入范围、环境、用例与通过标准的测试计划。
- **35 风险登记表** —— 汇总风险条目生成按等级排序的登记表。
- **36 路线图时间线** —— 按季度与阶段目标生成时间线区块。
- **37 缺陷报告模板** —— 插入环境、复现步骤、预期与实际的缺陷报告。
- **38 更新日志条目** —— 整理「新增 / 修复 / 优化」条目为标准变更日志区块。
- **39 故障复盘报告** —— 插入概述、时间线、根因、影响、改进五段复盘模板。
- **40 文档评审轮次** —— 生成轮次、评审人、意见与结论的评审表。

### 分组五 · 协作 · 分派与交付（10 款）

- **41 负责人看板** —— 按 @负责人 标记汇总任务与完成数看板。
- **42 RACI 责任矩阵** —— 插入行工作项、列角色的责任分工矩阵。
- **43 联系人卡片** —— 插入姓名、角色、职责、渠道、时区的联系人卡片。
- **44 交接文档模板** —— 插入状态、背景、进行中、待办与注意交接模板。
- **45 项目状态周报** —— 生成进度、风险与下一步计划的状态周报。
- **46 团队术语表** —— 汇总「术语：定义」条目去重排序生成术语表。
- **47 项目启动简报** —— 插入背景目标、范围、里程碑、分工与沟通机制简报。
- **48 任务催办清单** —— 按负责人分组汇总未完成催办项。
- **49 分享摘要卡片** —— 提炼标题、要点与待办数量生成分享摘要。
- **50 同步简报** —— 统计文档规模、修改痕迹与待办变化生成同步简报。

## 质量门禁

`plugin-market/validate.mjs` 对全部 50 款插件逐条执行 6 类校验，任一失败即判 FAIL：

| 阶段 | 校验内容 |
| --- | --- |
| A 文件 | 命名 `NN-<id>.js` 与 PLAN 一致、体积 ≤ 12 KB、LF 换行、末尾换行、文件头注释 |
| B 静态 | 单一默认导出、单一 `registerCommand`、无禁用标识符、api 白名单、无 import |
| C 契约 | 源码内 id / name / version / commandId / commandTitle 与 PLAN.json 逐字一致 |
| D 运行 | 五类样本文档均不抛异常、notify 恰好一次、输出不损坏正文 |
| E 幂等 | section / inplace 模式连续两次执行结果完全一致 |
| F 结构 | section 模式标记成对且唯一 |

运行校验（D）使用**五类样本文档**：富文（含标题、待办、引用、表格、代码块）、空文档、最小文档、纯代码块文档、220 行大文档；其中纯代码块样本文档用于验证「围栏代码块内不处理」，避免把代码里的 `# 标题`、`- [ ]`、`| 表格 |` 误当正文。幂等实测（E）对 non-append 模式的插件在富文与大文档上连续执行两次逐字节比对。

## 安装与启用

1. 打开应用 → 插件中心 → 插件市场；
2. 在「50 款日常与协作插件套件」中浏览或搜索目标插件；
3. 点击「一键安装」，安装后插件出现在「已安装」列表，可单独开关启用；
4. 亦可「导入本地插件脚本」：选择 `plugin-market/plugins/` 下的 `.js` 文件逐个导入，或使用 `plugin-market/install-local.js` 批量写入本地已安装列表。

插件启用后，在编辑器命令面板（`Ctrl+P`）搜索插件名即可执行对应命令。

## 发布与上架

插件文件确认通过校验后，由维护者统一通过「个人中心 → 插件市场与开放平台 → 发布插件」逐条提交，或按 `plugin-market/publish-plan.md` 的参数表批量填写（`PLAN.json` 已含全部元数据：id / name / version / category / icon / description / readme）。

插件市场只走官方服务（`https://md.zhengl.vip`），**不支持私有化部署**；本地验证使用「导入本地插件脚本」或 `install-local.js`。

## 升级注意事项

- 本版为**新增功能**，不改变既有编辑器、同步、主题等行为，无需迁移既有文档。
- 插件在宿主中「注册即执行」，一个插件只注册一个命令；安装多款插件互不冲突，文档区块以 `<!-- nm:<id> -->` 标记隔离。
- 插件在 Web / Windows PC / Android 三个宿主运行，仅依赖 6 个宿主 API 与纯 JS 运行时；若未来宿主收紧运行时，需先回归本套件。

## 已知限制

- 插件为单文件、无网络、无异步设计，因此不提供云端实时协作、外部数据拉取等能力；相关需求需在后续版本以独立机制实现。
- `mode: append` 类模板插件的输出块含日期/标题以便区分，但不自动去重；同一天多次执行会产生多份模板（按 SPEC 设计允许）。
- `mode: inplace` 类插件的修正范围限定在正文（跳过围栏代码块），不含图片、附件等非文本内容。
