## 1.3.0 — 2026-10-30

本版是 Neo MD 的**首个插件生态版本**：上线插件商店「50 款日常与协作插件套件」，覆盖记录、整理、会议、评审、分派五类高频环节；配套 6 类校验门禁保证三端一致。

### Added

- **插件商店 50 款日常与协作插件**：按 5 个分组上架，均为单文件 ES 模块，仅调用 6 个宿主 API，无网络 / 无 DOM / 无异步。
  - 日常使用 · 时间与日志（10 款）：每日站会日志、日终复盘、时间块规划等。
  - 日常使用 · 写作与整理（10 款）：字数仪表盘、目录重建、标题自动编号等。
  - 日常任务 · 协作会议（10 款）：会议纪要简报、议程生成器、行动项汇总等。
  - 协作 · 评审与复盘（10 款）：代码评审清单、风险登记表、故障复盘报告等。
  - 协作 · 分派与交付（10 款）：负责人看板、RACI 责任矩阵、任务催办清单等。
- **三种输出模式**：`append`（模板追加）/ `section`（标记区块，幂等刷新）/ `inplace`（就地改写，幂等），满足模板生成与文档整理的通用形态。
- **插件市场安装与本地导入双通道**：插件中心 → 插件市场 → 一键安装；或本地导入 `.js` / `install-local.js` 批量写入。

### Quality

- **插件校验器 `plugin-market/validate.mjs`**：对 50 款逐条执行 6 类校验——文件（命名 / 体积 / 换行 / 文件头）、静态（单导出 / 单命令 / 禁用标识符 / api 白名单 / 无 import）、契约（元数据与 PLAN 逐字一致）、运行（五类样本文档不抛异常 / notify 恰好一次）、幂等（section / inplace 连续两次结果一致）、结构（section 标记成对唯一）。
- **五类样本文档 + 幂等实测**：富文 / 空文档 / 最小文档 / 纯代码块文档 / 大文档逐一执行；纯代码块样本验证围栏内不处理，non-append 插件在富文与大文档上二次执行逐字节比对。

### Docs

- 新增插件实现规范 `plugin-market/SPEC.md`：文件位置与命名、模块契约、可用宿主 API、禁用项、三种输出模式与幂等要求、健壮性要求、工具函数与文案规范、完整参考实现、自检与发布。
- 新增插件权威数据 `plugin-market/PLAN.json`：50 款插件的序号 / 文件 / id / 名称 / 分组 / 分类 / mode / 描述 / readme 全量元数据。
- 新增版本迭代记录 `plugin-market/reports/release-notes-1.3.0.md` 与可粘贴 `changelog-1.3.0.md`。

### Deploy

- **插件市场恒走官方服务**：发布经「个人中心 → 插件市场与开放平台 → 发布插件」逐条或按 `publish-plan.md` 批量填写；市场不支持私有化部署，仅 `https://md.zhengl.vip` 一条通道。
